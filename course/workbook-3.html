심화 3회차 워크북

AI에게 일 시키기 · 입문 특강. 지시문 옆 복사 버튼을 누르고 [ ] 칸을 내 정보로 바꿔 붙여넣으세요.

이 회차에서 할 일

  1. 내 이메일로 만든 내 계정에 내가게를 올립니다.
  2. 나온 주소를 내 휴대폰에서 열어 봅니다.
  3. 내가게를 zip으로 묶어 백업하고, 계정 메모 카드를 만듭니다.

카드 3-0. 시작 전 확인

목표: 오늘 할 일의 준비물이 다 있는지 본다. 하는 일

  1. 바탕화면의 내가게 폴더를 연다
  2. 안에 index.html이 보이는지 본다
  3. index.html을 더블클릭해 내 가게 페이지가 열리는지 본다
  4. 수업용 이메일을 열 수 있는지 본다
  5. 휴대폰에서 카카오톡을 열 수 있는지 본다

성공 기준: 내 가게 이름이 보이는 페이지가 열린다. 막힐 때: 페이지가 안 열린다 → 손을 들어 주세요. 이메일 비밀번호가 기억나지 않는다 → 손을 들어 주세요(비밀번호를 말하거나 적어서 보여 주지 마세요).

카드 3-1. 소유란? 세 가지

목표: 내 것이 되려면 무엇이 내 손에 있어야 하는지 안다. 하는 일

  1. 아래 표를 읽는다
  2. 오른쪽 칸에 "내 것인가?"를 O, X로 적는다(오늘 수업이 끝나면 다시 본다)
소유 요소 쉬운 말 내 것이 되는 조건 지금 내 것인가? (O/X)
호스팅 계정 가게를 올려 두는 건물의 계약서 내 이메일로 내가 가입한 계정
도메인 가게 간판의 주소 (연 단위로 빌림) 내 이름으로 구입, 갱신을 놓치지 않음
사이트 파일 인테리어 설계도 내가게 폴더를 내 컴퓨터와 USB·드라이브에 보관

기억할 한 줄: 제작자(업체·지인·강사) 이름으로 만든 계정에 올리면 내 것이 아닙니다. 성공 기준: 세 가지 이름을 보지 않고 말할 수 있다. 막힐 때: 용어가 헷갈린다 → 손을 들어 주세요.

카드 3-2. 올리기 전 점검 — 공개됩니다

목표: 인터넷에 올려도 되는 내용인지 내 눈으로 확인한다. 올리면 주소를 아는 사람은 누구나 볼 수 있습니다.

하는 일

  1. 내가게의 index.html을 열어 처음부터 끝까지 천천히 읽는다
  2. 아래 체크 항목을 하나씩 확인한다

병원은 오늘 가상 정보로 연습합니다. 환자 정보는 어디에도 넣지 않습니다.

성공 기준: 아래 네 가지가 모두 체크된다. 막힐 때: 맨 위 "연습용" 표시가 없다 → 아래 문장을 Claude에게 보내고, 바뀐 index.html을 다시 열어 확인하세요.

페이지 맨 위에 작게 "수업 연습용 페이지입니다"라고 넣어 주세요.

카드 3-3. 호스팅 계정 가입 (내 이메일로)

목표: 내 이메일로 가입한 내 계정을 만든다.

올리는 서비스는 Cloudflare Pages 또는 Netlify Drop 중 수업 전에 하나로 정해집니다. 오늘 쓰는 곳: [리허설 후 확정: 서비스 이름]

하는 일 (아래는 틀이고 클릭 단계는 수업 전에 채워집니다)

  1. 가입 주소를 연다: [리허설 후 확정: 주소]
  2. 이메일 칸에 내 이메일을 넣는다 (업체·강사 이메일이 아닙니다)
  3. 비밀번호 칸에 내가 직접 비밀번호를 넣는다 (옆 사람·강사·AI가 대신 넣지 않습니다. 종이나 이 문서에 적지 않습니다)
  4. [리허설 후 확정: 가입 버튼 이름과 위치]
  5. 내 이메일로 온 인증 메일을 연다 [리허설 후 확정: 메일 제목과 인증 방법]
  6. 로그인된 내 계정 화면이 보이는지 확인한다 [리허설 후 확정: 성공 화면 설명]
  7. 돈을 내라는 화면이 나오면 멈추고 손을 들어 주세요 [확인 필요: 결제 수단 요구 여부]

성공 기준: 내 이메일로 가입한 내 계정 화면이 보인다. 막힐 때:

  • 인증 메일이 안 온다 → 스팸함을 보고, 그래도 없으면 손을 들어 주세요
  • 화면이 영어라서 모르겠다 → 손을 들어 주세요 (보조가 같이 봅니다)
  • 20분이 지나도 안 된다 → 쉬는 시간에 이어서 도와드립니다

카드 3-4. 올릴 폴더 모양 확인

목표: index.html이 폴더 맨 위에 있는지 확인한다. 하는 일

  1. 바탕화면의 내가게 폴더를 더블클릭해서 연다
  2. 열자마자 index.html이 바로 보이는지 본다
  3. 폴더 안에 또 내가게 같은 폴더가 하나만 있고 그 안에 index.html이 있다면, 그 안의 파일들을 위 폴더로 옮긴다(손을 들어 주세요)
  4. 공개하면 안 되는 파일(메모, 개인 서류)이 내가게 안에 없는지 본다

성공 기준: 내가게를 열면 index.html이 바로 보인다. 막힐 때: index.html이 한 겹 안쪽에 있다 → 손을 들어 주세요. 파일 이름이 index.html.txt처럼 보인다 → 손을 들어 주세요.

카드 3-5. 끌어다 놓아 올리기

목표: 내가게를 내 계정에 올려 주소를 얻는다. 하는 일 (틀이고 클릭 단계는 수업 전에 채워집니다)

  1. 내 계정 화면에서 올리는 곳으로 간다 [리허설 후 확정: 메뉴 이름]
  2. 내가게 폴더(또는 zip)를 올리는 칸 위로 끌어다 놓는다 [리허설 후 확정: 폴더로 할지 zip으로 할지]
  3. 올라가는 것이 끝나길 기다린다 [리허설 후 확정: 완료 표시]
  4. 서비스가 보여 주는 주소를 복사한다 [리허설 후 확정: 주소 위치]

성공 기준: https://로 시작하는 주소가 생겼다. 막힐 때:

  • 끌어다 놓아도 반응이 없다 → 마우스 왼쪽 버튼을 누른 채 칸 위까지 옮기고 놓으세요. 안 되면 손을 들어 주세요
  • 올라갔는데 내용이 이상하다 → index.html 위치를 카드 3-4로 다시 확인하세요
  • 20분 안에 못 올려도 괜찮습니다. 쉬는 시간에 이어서 도와드립니다

    주소가 생겼다고 끝난 것이 아닙니다. 다음 카드에서 휴대폰으로 열어야 완료입니다.

카드 3-6. 휴대폰으로 열어 보기 (직접 확인!)

목표: 내 휴대폰에서 내 사이트가 열리는지 눈으로 확인한다. 하는 일

  1. 3-5에서 복사한 주소를 카카오톡 '나에게 보내기'로 보낸다
  2. 휴대폰에서 카카오톡의 그 메시지를 열고 주소를 누른다
  3. 가게(의원) 이름, 시간, 전화번호가 보이는지 확인한다
  4. 전화번호를 눌러 전화 연결 화면이 뜨는지 본다 (실제로 걸지 않아도 됩니다)
  5. 열린 화면을 사진으로 찍어 둔다

성공 기준: 휴대폰에서 내 가게 페이지가 열린다. 막힐 때:

  • 페이지가 안 열린다 → 주소가 https://로 시작하는지, 글자가 빠지지 않았는지, 와이파이/데이터가 켜져 있는지 보세요. 그래도 안 되면 손을 들어 주세요
  • 예전 페이지나 빈 화면이 보인다 → 손을 들어 주세요

    AI나 사이트가 "올렸습니다"라고 말한 것만으로는 완료가 아닙니다. 내 휴대폰에서 열려야 완료입니다.

카드 3-7. 백업 — 내가게를 zip으로 묶어 보관

목표: 파일을 내 손에 따로 보관한다. 하는 일

  1. 바탕화면에서 내가게 폴더 위에 마우스 오른쪽 버튼을 누른다
  2. 압축 메뉴를 고른다 [화면 확인 필요: Windows 11 / Mac 메뉴 이름]
  3. 만들어진 zip 파일의 이름을 내가게-백업-날짜.zip으로 바꾼다 (예: 내가게-백업-1107.zip)
  4. USB 또는 드라이브(구글 드라이브 등)에 이 zip 파일을 복사한다 [화면 확인 필요: 복사 방법은 강사 시연]
  5. USB·드라이브를 열어 zip이 들어 있는지 눈으로 본다

성공 기준: 내 컴퓨터와 USB·드라이브, 두 군데에 zip이 있다. 막힐 때: 압축 메뉴가 안 보인다 → 손을 들어 주세요. USB가 인식되지 않는다 → 손을 들어 주세요.

카드 3-8. 계정 메모 카드

목표: 계정을 잃어버리지 않도록 정보 위치를 적는다. 계정을 잃으면 사이트를 고칠 수 없습니다. 비밀번호는 적지 않습니다.

칸 내가 적는 내용

비밀번호는 어디에 보관하나 (장소 이름만, 비밀번호 자체는 적지 않기)

성공 기준: 비밀번호를 뺀 모든 칸을 채웠다. 막힐 때: 복구 이메일이 있는지 모르겠다 → 손을 들어 주세요. 비밀번호가 기억나지 않는다 → 손을 들어 주세요(적지 마세요).

카드 3-9. 삭제·비공개 방법

목표: 연습용으로 올린 사이트를 내릴 수 있다. 하는 일 (틀이고 단계는 수업 전에 채워집니다)

  1. 내 계정에 로그인한다
  2. 올린 사이트를 고른다 [리허설 후 확정: 메뉴 이름]
  3. 삭제 또는 비공개를 고른다 [리허설 후 확정: 버튼 이름과 확인 문구]
  4. 휴대폰에서 3-6의 주소를 다시 열어 더 이상 열리지 않는지 본다

성공 기준: 삭제한 뒤 같은 주소가 열리지 않는다. 막힐 때: 삭제 버튼을 못 찾겠다 → 손을 들어 주세요. 오늘은 삭제하지 않고 방법만 익혀도 됩니다. 알아 둘 것: 이미 본 사람이 화면을 저장했거나 검색에 남은 내용은 내려도 남아 있을 수 있습니다.

카드 3-10. (선택) 도메인 — 내 이름의 주소

목표: 도메인이 무엇이고 무엇이 필요한지 안다. (오늘은 안내만, 구입은 선택) 알아 둘 것

  1. 도메인 = 연 단위로 빌리는 내 명의 주소입니다. 갱신을 놓치면 잃을 수 있습니다
  2. 돈이 듭니다. 가격: [확인 필요: 가격]
  3. 구입과 결제는 내가 직접 합니다. 강사·AI가 대신 하지 않습니다
  4. 구입 뒤 내 사이트와 연결(DNS)하는 일은 어렵습니다. 업체 상담이나 강사 보조와 함께 합니다
  5. 도메인이 없어도 사이트는 서비스가 준 주소로 열립니다

하는 일

  1. 도메인이 필요한지 아래에서 고른다
  2. 필요하면 구입처와 가격을 알아보는 숙제를 적는다

성공 기준: "도메인은 돈이 들고, 구입은 내가 직접, 연결은 도움받기" 세 가지를 말할 수 있다. 막힐 때: 판단이 안 선다 → 지금은 사지 않아도 됩니다. 손을 들어 주세요.

  3. 4회차에 가져올 것을 확인한다

심화 2회차 워크북

AI에게 일 시키기 · 입문 특강. 지시문 옆 복사 버튼을 누르고 [ ] 칸을 내 정보로 바꿔 붙여넣으세요.

이 회차에서 할 일

  1. Claude 앱의 Code 탭에서 바탕화면 내가게 폴더를 열고, 말로 시켜 index.html 홈페이지 파일 하나를 만듭니다.
  2. 폴더에서 index.html을 더블클릭해 직접 열고, 말로 두 번 고칩니다.
  3. 가격·시간·전화를 내 눈으로 확인합니다. 오늘은 인터넷에 올리지 않습니다(다음 시간).

카드 2-0. 복습: 앱을 다시 열고 내가게 폴더 열기

목표: Code 탭에서 내가게 폴더가 열린 상태로 시작한다. 하는 일

  1. Claude 앱을 켠다.
  2. 상단 사이드바의 Code 탭을 누른다.
  3. 환경은 Local을 고른다 [화면 확인 필요: Local 선택 위치].
  4. 프로젝트 폴더 메뉴에서 Open folder… 를 누른다.
  5. 바탕화면의 내가게 폴더를 고른다. (내 이름 폴더인 C:\Users\이름 전체를 고르지 않습니다.)
  6. 권한 모드가 Manual인지 확인한다. 아니면 손을 든다 [화면 확인 필요: 권한 모드 표시 위치, Manual / Accept edits / Auto 중 선택].
  7. 아래 약속 3가지를 소리 내어 읽는다.

성공 기준: 화면에 내가게 폴더 이름이 보이고, 글 쓰는 칸이 보인다. 막힐 때: Code 탭이 안 보인다 → 손을 들어 주세요(유료 구독 로그인 상태 확인이 필요합니다). 폴더 목록에 내가게가 없다 → 손을 들어 주세요.

카드 2-2. "좋아요" 하고 만들게 하기

목표: AI가 내가게 폴더 안에 index.html 파일을 직접 만들게 한다.

알아 둘 것

  • 채팅 화면과 달리 Code 탭의 AI는 내 폴더 안에 파일을 직접 만듭니다. 복사해서 저장하지 않아도 됩니다.
  • 파일을 만들거나 고치기 전에, 무엇이 바뀌는지 변경 표시(diff) 로 보여 주고 내 승인을 기다립니다. (Manual 모드) [화면 확인 필요: 변경 표시의 모양, 승인·거절 버튼의 이름]
  • 처음 만드는 파일은 전부 새로 추가되는 내용이라 길게 보일 수 있습니다. 코드를 읽을 필요는 없습니다.

하는 일

  1. 아래 문장을 붙여넣고 보낸다.
  2. 변경 표시가 나오면, 아래 승인 기준을 확인한다.
  3. 기준에 맞으면 승인 버튼을 누른다 [화면 확인 필요: 승인 버튼 이름].
  4. AI의 답 두 가지를 읽는다.

붙여넣을 문장

좋아요. 이제 만들어 주세요.
다 만든 뒤에 아래 두 가지를 알려 주세요.
1. 제가 준 정보와 다르게 쓴 부분이 있는지, "[입력 필요]"로 남긴 곳은 어디인지
2. 만든 파일의 이름과 위치

승인 기준

  • 파일 이름이 index.html 이다
  • 위치가 내가게 폴더 안이다
  • 다른 이름·다른 폴더가 보이면 승인하지 말고 손을 든다

성공 기준: 내가게 폴더 안에 index.html 파일이 생겼고, AI가 파일 이름과 위치를 알려 주었다. 주의: 1번은 AI의 자체 점검일 뿐입니다. AI가 "다른 점 없음"이라고 해도 내가 직접 카드 2-5에서 가격·시간·전화를 눈으로 맞춰 봅니다. 막힐 때: 승인 버튼이 안 보인다 → 화면을 아래로 내려 보고, 그래도 없으면 손을 들어 주세요. 파일이 안 만들어졌다 → "index.html 파일을 내가게 폴더에 만들어 주세요"라고 보내세요.

카드 2-3. 폴더에서 열어 보기

  2. 안에 있는 index.html 을 찾는다.
  3. index.html을 더블클릭한다.
  4. 인터넷 창이 열리고 우리 가게(의원) 페이지가 뜬다.
  5. 맨 위에 "수업 연습용 페이지입니다"가 있는지 본다.

성공 기준: 내 가게 이름이 보이는 페이지가 열린다. 막힐 때: 글자가 깨진다 → Code 탭에 아래를 보내세요.

한글이 깨지지 않게 다시 만들어 주세요.

index.html이 메모장 같은 다른 프로그램으로 열린다 → 손을 들어 주세요 [화면 확인 필요: 연결 프로그램 처리]. 파일이 폴더에 없다 → 카드 2-2로 돌아가세요. 참고: 주소창에 file:/// 같은 글자가 보이면 정상입니다. 아직 내 컴퓨터 안에서만 보이는 중이고, 인터넷에 올라간 것이 아닙니다.

카드 2-4. 말로 고치기 2번

목표: 코딩을 몰라도 말로 두 번 고친다.

하는 일

  1. 아래 고치기 문장 중 하나를 고른다(또는 내 말로 쓴다). 한 번에 하나만 고칩니다.
  2. Code 탭에 붙여넣고 보낸다.
  3. 변경 표시가 나오면 어디가 바뀌는지 훑어보고, 카드 2-2의 승인 기준에 맞으면 승인한다. (이번에는 고치는 곳만 표시되어 읽기 쉽습니다)
  4. 인터넷 창으로 가서 새로고침한다. [화면 확인 필요: 새로고침 버튼 위치, 또는 F5 키]

메뉴 가격이 더 눈에 띄게 해 주세요.  (병원: 진료시간이 더 눈에 띄게 해 주세요.)

Manual 모드란: AI가 파일에 손대기 전에 매번 나에게 물어보는 모드입니다. 오늘은 이 모드로 승인 창을 직접 봅니다. Accept edits, Auto 모드가 있다는 것만 알아 두세요. 오늘은 바꾸지 않습니다.

성공 기준: 말한 대로 바뀐 것이 새로고침한 인터넷 창에서 보인다. 안 바뀌면 같은 말을 더 구체적으로 다시 합니다(예: "글자를 두 배로 크게"). 막힐 때: 승인했는데 안 바뀐 것처럼 보인다 → 인터넷 창을 새로고침했는지 보세요. 승인을 거절했다 → 같은 말을 다시 보내세요. 엉뚱하게 바뀌었다 → "방금 바꾼 것을 원래대로 되돌려 주세요"라고 보내세요.

카드 2-6. 병원 원장님 주의 (자영업자도 읽어 두세요)

목표: 의료 관련 문구를 AI에게만 맡기지 않는다.

지우게 하는 문장

제가 주지 않은 안내 문장이 들어 있으면 모두 알려 주시고, 제가 허락하기 전에는 지워 주세요.

참고: 이 카드는 병원이 아니어도 "AI가 쓴 말은 내가 읽고 책임진다"는 연습입니다.

카드 2-7. 숙제: 진짜 정보로 한 번 더 고쳐 보기

목표: 다음 시간 전에 내 진짜 정보로 홈페이지를 한 번 더 고쳐 본다.

하는 일

  1. Claude 앱 → Code 탭 → 내가게 폴더를 연다 (카드 2-0).
  2. 가격·시간·전화·주소 같은 진짜 정보를 종이에 먼저 정리한다. 병원은 가상 정보를 그대로 써도 됩니다. 진짜 정보를 넣었다면 원장이 검수한 뒤에만 씁니다.
  3. 고치고 싶은 곳을 한 번에 하나씩 말로 시킨다.
  4. 승인 → 인터넷 창 새로고침으로 확인한다.
  5. 카드 2-5의 확인 체크를 한 번 더 한다.

하지 않는 것: 손님·환자 이름, 비밀번호, 카드번호를 넣지 않습니다. 인터넷에 올리지 않습니다(다음 시간에 같이 합니다).

성공 기준: 진짜 정보가 들어간 index.html이 내 컴퓨터에서 열리고, 숫자를 내 눈으로 맞춰 보았다. 막힐 때: 앱이 안 열리거나 Code 탭이 안 보인다 → 다음 시간 시작 전에 알려 주세요. 혼자 하기 어려우면 안 해도 됩니다. 다음 시간에 같이 합니다.

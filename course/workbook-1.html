카드 1-1. 바탕화면에 내가게 폴더 만들기

목표: 앞으로 모든 파일을 넣을 서랍 하나를 만듭니다. 하는 일

  1. 열려 있는 창을 모두 작게 하여 바탕화면(바탕 그림이 보이는 화면)을 봅니다. 윈도는 창문 키를 누른 채 D를 누르면 됩니다.
  2. 바탕화면의 빈 곳에서 마우스 오른쪽 버튼을 누릅니다 (맥은 두 손가락으로 누르기).
  3. 윈도는 「새로 만들기」 → 「폴더」, 맥은 「새로운 폴더」를 고릅니다 [화면 확인 필요: 메뉴 이름].
  4. 이름 칸이 파랗게 반짝이면 내가게를 입력하고 Enter를 누릅니다. 한글이 안 써지면 한/영 키를 한 번 누릅니다.
  5. 띄어쓰기 없이 내가게 세 글자인지 확인합니다.

성공 기준: 바탕화면에 이름이 내가게인 폴더 그림이 보인다. 막힐 때: 이름이 새 폴더로 남았다 → 폴더에서 오른쪽 버튼 → 「이름 바꾸기」 [화면 확인 필요]. 이름 칸이 사라졌다 → 손을 들어 주세요.

카드 1-2. 파일은 저장할 때 위치를 고릅니다

목표: 파일을 내가게 안에 저장하고, 저장 위치를 눈으로 확인합니다. 하는 일

  1. 메모 프로그램을 엽니다. 윈도는 창문 키를 누르고 메모장을 입력한 뒤 Enter. 맥은 command와 스페이스바를 같이 누르고 텍스트편집기를 입력한 뒤 Enter [화면 확인 필요].
  2. 맥이라면 위쪽 메뉴 「포맷」 → 「일반 텍스트 만들기」를 한 번 누릅니다 [화면 확인 필요].
  3. 흰 칸에 연습입니다라고 입력합니다.
  4. 저장합니다. 윈도는 Ctrl을 누른 채 S, 맥은 command를 누른 채 S.
  5. 저장 창이 뜨면 파일 이름 칸에 연습을 입력합니다.
  6. 저장 창의 왼쪽에서 「바탕화면」을 누르고, 보이는 내가게 폴더를 두 번 눌러 안으로 들어갑니다 [화면 확인 필요: 맥은 저장 위치 고르는 칸이 다름].
  7. 창 위쪽에 내가게가 표시되어 있는지 눈으로 확인한 뒤 「저장」을 누릅니다.
  8. 메모 프로그램을 닫습니다.
  9. 바탕화면의 내가게 폴더를 두 번 눌러 엽니다.

성공 기준: 내가게 폴더 안에 연습이라는 파일이 보인다. 막힐 때: 폴더 안에 파일이 없다 → 바탕화면이나 다른 곳에 저장된 것입니다. 손을 들어 주세요. 파일을 끌어서 내가게에 넣으면 됩니다.

카드 1-3. 파일 이름 뒤 꼬리표(확장자) 보이게 하기

목표: 파일의 종류가 이름 뒤에 보이게 설정합니다. 하는 일

  1. 내가게 폴더 창을 엽니다 (카드 1-2 마지막 상태).
  2. 윈도 11: 창 위쪽 「보기」 → 「표시」 → 「파일 확장명」에 체크합니다 [화면 확인 필요].
  3. 윈도 10: 창 위쪽 「보기」 탭 → 「파일 확장명」에 체크합니다 [화면 확인 필요].
  4. 맥: 바탕화면을 한 번 누른 뒤 위쪽 메뉴 「Finder」 → 「설정」 → 「고급」 → 「모든 파일 확장자 보기」에 체크합니다 [화면 확인 필요].
  5. 연습 파일 이름을 다시 봅니다.

성공 기준: 파일 이름이 연습.txt처럼 점과 글자가 뒤에 붙어 보인다. 막힐 때: 체크했는데도 안 보인다 → 창을 닫았다가 내가게를 다시 엽니다. 그래도 안 되면 손을 들어 주세요.

카드 1-4. 복사하고 붙여넣기

목표: 글자를 복사해서 붙여넣는 방법을 몸에 익힙니다. 오늘부터 지시문은 전부 복사해서 붙여넣습니다. 하는 일

  1. 내가게 폴더에서 연습 파일을 두 번 눌러 엽니다.
  2. 마우스 왼쪽 버튼을 누른 채 글자 위를 끌어서 연습입니다를 선택합니다 (글자가 파랗게 바뀝니다).
  3. 복사합니다. 윈도는 Ctrl을 누른 채 C, 맥은 command를 누른 채 C.
  4. 글자 뒤 빈 곳을 한 번 누르고 Enter 키로 줄을 바꿉니다.
  5. 붙여넣습니다. 윈도는 Ctrl을 누른 채 V, 맥은 command를 누른 채 V.
  6. 한 번 더 붙여넣습니다.
  7. 키보드가 어려우면 마우스 오른쪽 버튼 → 「복사」, 「붙여넣기」를 써도 됩니다.
  8. 저장하고 (Ctrl+S, 맥은 command+S) 닫습니다.

성공 기준: 파일 안에 연습입니다가 세 번 보인다. 막힐 때: 글자가 안 붙는다 → 복사할 때 글자가 파랗게 선택되었는지 확인하고 3번부터 다시 합니다.

카드 1-5. 다운로드 폴더 찾기

목표: 인터넷에서 받은 파일이 들어가는 곳을 압니다. 잠시 뒤 설치 파일이 여기에 들어옵니다. 하는 일

  1. 윈도: 화면 아래 작업 표시줄의 노란 폴더 그림(파일 탐색기)을 누릅니다. 맥: 화면 아래 줄 오른쪽의 「다운로드」 또는 Finder 창을 엽니다 [화면 확인 필요].
  2. 창 왼쪽 목록에서 「다운로드」를 누릅니다.
  3. 안에 들어 있는 파일들을 봅니다. 방금 받은 파일은 보통 맨 위나 오늘 날짜로 보입니다.
  4. 창을 닫습니다.
  5. 다시 열어서, 「다운로드」를 스스로 찾아 봅니다.

성공 기준: 「다운로드」 폴더를 스스로 열고 닫을 수 있다. 막힐 때: 왼쪽 목록에 「다운로드」가 안 보인다 → 손을 들어 주세요.

카드 1-6. 크롬 — 주소창과 탭

  1. 크롬을 엽니다 (동그란 빨강·노랑·초록·파랑 그림. 없으면 손을 들어 주세요).
  2. 창 맨 위의 긴 칸이 주소창입니다. 한 번 누릅니다.
  3. 아래 주소를 복사해서 붙여넣고 Enter를 누릅니다.
claude.ai
  1. 맨 위 줄의 + 모양을 눌러 새 탭을 엽니다.

카드 1-7. Claude 가입과 유료 구독 안내

  • 무료 플랜에는 오늘 쓸 Claude Code가 없습니다. Code 탭을 쓰려면 유료 구독이 필요합니다.

하는 일

  1. 크롬 주소창에 claude.ai를 입력해 엽니다.

성공 기준: claude.ai에 로그인된 첫 화면이 보인다. 막힐 때: 확인 메일이 안 온다 → 스팸 메일함도 봅니다. 그래도 없으면 손을 들어 주세요. 이메일 주소가 틀렸을 수 있습니다.

카드 1-9. 로그인하고 Code 탭 찾기

카드 1-10. 내가게 폴더 열기와 권한 모드

목표: Claude가 일할 서랍을 내가게 하나로 정하고, 안전하게 시작합니다. 하는 일

  1. Code 화면에서 프로젝트 폴더 메뉴를 누릅니다 [화면 확인 필요: 메뉴 위치].
  2. 「Open folder…」를 누릅니다.
  3. 열린 창에서 「바탕화면」 → 내가게를 고르고 폴더를 선택합니다 [화면 확인 필요: 선택 버튼 이름].
  4. 실행 환경은 Local을 고릅니다 [화면 확인 필요: 선택 위치].
  5. 권한 모드를 Manual로 맞춥니다. Manual은 "AI가 파일을 바꾸기 전에 나에게 먼저 묻는 방식"입니다 [화면 확인 필요: 권한 모드 선택 위치].
  6. 같은 목록의 Accept edits, Auto는 오늘 건드리지 않습니다.
  7. 화면 어딘가에 내가게라는 이름이 보이는지 확인합니다.

성공 기준: Code 화면에 내가게가 열려 있고, 모드가 Manual이다. 막힐 때: 폴더가 안 열린다 → 이름이 정확히 내가게인지, 바탕화면에 있는지 확인하고 2번부터 다시 합니다. 내 이름이 붙은 큰 폴더(사용자 폴더)를 통째로 열지 마세요. 손을 들어 주세요.

  1. Code 화면 아래의 글 쓰는 칸을 한 번 누릅니다.
  2. 아래 지시문을 복사해서 붙여넣습니다.
이 폴더에 내 가게 이름을 적은 메모 파일을 만들어 줘.
가게 이름은 [  ] 입니다.
파일 이름은 메모.txt 로 해 줘.
  1. [ ]를 지우고 내 가게 이름으로 바꿉니다 (병원은 가상 이름).
  2. 보냅니다 [화면 확인 필요: 전송 방법].

성공 기준: 승인 요청을 읽고 허용했으며, AI가 끝났다는 말을 한다. 막힐 때: 승인 창이 안 뜬다 → 조금 기다리고, 그래도 없으면 손을 들어 주세요. 엉뚱한 폴더나 이름이 보이면 허용하지 말고 손을 들어 주세요.

  5. 틀리면 Claude로 돌아가 아래를 보냅니다.
메모.txt 안의 가게 이름을 [맞는 이름] 으로 고쳐 줘.
  1. 승인 요청을 읽고 허용한 뒤, 파일을 다시 열어 확인합니다.

성공 기준: 내가 직접 연 파일에 내 가게 이름이 적혀 있다. 막힐 때: 파일이 없다 → AI가 "만들었다"고 해도 안 된 것입니다. Claude에게 "메모.txt가 내가게 폴더에 없어요. 다시 만들어 줘"라고 보내고, 안 되면 손을 들어 주세요.

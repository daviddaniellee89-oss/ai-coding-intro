수업 전 준비

AI에게 일 시키기 · 입문 특강. 지시문 옆 복사 버튼을 누르고 [ ] 칸을 내 정보로 바꿔 붙여넣으세요.

왜 수업 전에 준비하나요

수업은 3시간 안에 내 가게 홈페이지를 만들어 내 계정으로 올리는 것까지 합니다. 가입, 결제, 설치는 시간이 오래 걸리고 막히기 쉬워서 수업 전에 미리 해 옵니다. 혼자 하기 어려우면 수업 전 점검 시간에 함께 합니다(카드 사전-7).

수업 전에 끝낼 것 한눈에

  1. 비용 이해하고 구독 결정
  2. 컴퓨터가 되는지 확인
  3. 이메일 준비
  4. Claude 가입 + 구독
  5. Claude 앱 설치 + 로그인
  6. 인터넷 올릴 서비스 가입(내 이메일로)
  7. 가게(병원) 정보 메모

카드 사전-1. 돈이 드는 것

  1. 이 과정의 Claude Code는 무료 계정으로는 쓸 수 없습니다. 유료 구독이 필요합니다.
  2. 가격은 Anthropic 공식 가격 페이지(claude.com/pricing)에서 직접 확인하세요. 2026-11-07에 확인한 표기는 Pro 요금제 월 결제 $20, 연간 결제 시 월 $17(세금 별도, 가격은 바뀔 수 있음)입니다. 원화 가격과 한국 카드 결제 가능 여부는 확인하지 못했습니다. [확인 필요: 원화 가격·한국 결제]
  3. 결제는 본인이 직접 합니다. 카드 번호는 결제 화면 외에는 어디에도 적거나 말하지 않습니다.
  4. 해지는 로그인한 뒤 Settings → Billing → Cancel에서 합니다. 해지해도 현재 결제 기간이 끝날 때까지는 쓸 수 있고, 다음 결제를 피하려면 결제일 최소 24시간 전에 해지하라고 안내합니다(Anthropic 도움말, 2026-11-07 확인). 환불 조건은 찾지 못했으니 결제 전에 직접 확인하세요. [확인 필요: 환불 조건]
  5. 인터넷 올리는 서비스는 무료 한도 안에서 쓰는 것을 기준으로 합니다. [확인 필요: 한도와 약관]
  6. 내 이름의 인터넷 주소(도메인)는 오늘 수업에서 하지 않습니다. 필요하면 나중에 선택으로 합니다.

성공 기준: 비용을 이해했고, 구독할지 정했다.

카드 사전-2. 내 컴퓨터 확인

  1. 컴퓨터가 Windows 10 이상(11 포함), 또는 Mac(macOS 13 이상)인지 확인합니다.
  2. 메모리(램)를 확인합니다. 명령줄 Claude Code는 4GB 이상을 요구하지만, 앱의 메모리 요건은 공식 문서에서 찾지 못했습니다. [확인 필요: 앱 메모리 요건]
  3. 인터넷이 연결되는지 확인합니다.
  4. 노트북이면 전원 어댑터를 챙깁니다.

성공 기준: 내 컴퓨터가 조건에 맞는다. 막힐 때: 모르거나 맞지 않으면 신청 전에 문의합니다. [확인 필요: 문의 창구]

카드 사전-3. 이메일 준비

  1. 수업 내내 쓸 이메일 주소를 1개 정합니다.
  2. 그 이메일에 로그인해서 메일을 열어 봅니다.
  3. 비밀번호를 기억하지 못하면 비밀번호 찾기를 먼저 해 둡니다.
  4. 이 이메일이 Claude와 인터넷 올리는 서비스 가입에 같이 쓰입니다. 종이에 이메일 주소(비밀번호 말고)를 적어 둡니다.

성공 기준: 이메일에 로그인해서 받은 메일을 열어 볼 수 있다.

카드 사전-4. Claude 가입과 구독

  1. 크롬(인터넷 창)을 열고 주소창에 claude.ai를 입력합니다.
  2. 가입 또는 로그인 버튼을 누릅니다. [화면 확인 필요: 버튼 이름]
  3. 준비한 이메일로 가입하고 확인 메일 안내대로 진행합니다. [화면 확인 필요: 가입 방식]
  4. 요금 안내 화면에서 본인이 직접 읽고 구독합니다. [화면 확인 필요: 요금 화면 위치]
  5. 결제 뒤 처음 화면이 보이면 멈춥니다.

성공 기준: claude.ai에 로그인된 화면이 보이고, 구독이 되어 있다. 막힐 때: 확인 메일이 안 오면 스팸 메일함을 봅니다. 그래도 안 되면 점검 시간에 함께 봅니다.

카드 사전-5. Claude 앱 설치와 로그인

  1. 내 컴퓨터에 맞는 주소 한 줄을 복사합니다.

윈도 (64비트)

https://claude.ai/api/desktop/win32/x64/setup/latest/redirect

맥

https://claude.ai/api/desktop/darwin/universal/dmg/latest/redirect

[확인 필요: 주소가 지금도 유효한지, 윈도 ARM 지원]

  1. 인터넷 창의 새 탭 주소창에 붙여넣고 Enter를 누릅니다.
  2. 받은 파일을 두 번 눌러 설치합니다. [화면 확인 필요: 설치 안내 창]
  3. Claude 앱을 열고 로그인합니다. 비밀번호는 본인이 직접 입력합니다.
  4. 앱 위쪽에 Code 탭이 보이는지 확인합니다.

성공 기준: Claude 앱이 열려 있고 Code 탭이 보인다. 막힐 때: 주소가 안 열리거나 오류가 나면 점검 시간에 함께 봅니다. 유료 안내가 뜨면 카드 사전-4를 다시 봅니다.

카드 사전-6. 인터넷에 올릴 서비스 가입

  1. 오늘 쓸 서비스는 [서비스 이름] 입니다. [리허설 후 확정: 서비스 이름]
  2. 주소로 들어갑니다. [리허설 후 확정: 주소]
  3. 내 이메일로 가입합니다. 제작자나 다른 사람 계정으로 가입하지 않습니다.
  4. 이메일로 온 확인 메일을 열어 인증합니다. [리허설 후 확정: 인증 방법]
  5. 로그인된 첫 화면이 보이면 멈춥니다. 결제 수단을 요구하면 멈추고 점검 시간에 함께 봅니다. [확인 필요: 결제 수단 요구 여부]

성공 기준: 내 이메일로 로그인된 첫 화면이 보인다.

카드 사전-7. 준비물과 점검 시간

  1. 가게(병원) 정보 메모: 이름, 메뉴(진료과목), 영업시간(진료시간), 주소, 전화번호. 병원은 가상 정보로 준비합니다.
  2. 종이와 펜, 노트북 전원 어댑터.
  3. 위 카드 사전-4, 사전-5, 사전-6 중 하나라도 어려우면 수업 전 점검 시간을 신청합니다. [확인 필요: 점검 방식(방문·원격)과 시간]

수업 시작 때 보여 줄 것: Claude 앱이 열려 있고 Code 탭이 보이는 화면, 인터넷 올릴 서비스에 로그인된 화면.

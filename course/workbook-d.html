카드 2. 컴퓨터 기초 4가지

목표: 오늘 꼭 필요한 네 가지만 익힙니다. (1) 내가게 폴더 (2) 파일 저장 위치 (3) 꼬리표 보이기 (4) 더블클릭과 복사·붙여넣기

하는 일

  1. 폴더 만들기. 바탕화면의 빈 곳에서 마우스 오른쪽 버튼 → 「새로 만들기」 → 「폴더」(맥은 「새로운 폴더」)를 고릅니다 [화면 확인 필요: 메뉴 이름]. 이름은 내가게입니다. 띄어쓰기 없이 세 글자입니다. 이미 있으면 다음으로 갑니다.
  2. 저장 위치. 메모장(맥은 텍스트편집기)을 열고 연습입니다라고 입력한 뒤 저장합니다 (윈도 Ctrl+S, 맥 command+S). 저장 창에서 위치를 바탕화면의 내가게로 고르고, 파일 이름은 연습으로 합니다 [화면 확인 필요: 맥은 저장 위치 고르는 칸이 다름].
  3. 저장 창 위쪽에 내가게가 표시되는지 눈으로 확인한 뒤 「저장」을 누르고 메모 프로그램을 닫습니다.
  4. 꼬리표 보이기. 내가게 폴더를 엽니다. 윈도 11은 위쪽 「보기」 → 「표시」 → 「파일 확장명」, 윈도 10은 「보기」 탭 → 「파일 확장명」에 체크합니다. 맥은 Finder 메뉴의 「설정」 → 「고급」 → 「모든 파일 확장자 보기」에 체크합니다 [화면 확인 필요].
  5. 더블클릭. 연습.txt를 두 번 눌러 엽니다.
  6. 복사·붙여넣기. 글자를 끌어서 선택하고 복사합니다 (윈도 Ctrl+C, 맥 command+C). 줄을 바꾸고 붙여넣습니다 (윈도 Ctrl+V, 맥 command+V). 키보드가 어려우면 마우스 오른쪽 버튼의 「복사」「붙여넣기」를 써도 됩니다.
  7. 저장하고 닫습니다.

성공 기준: 내가게 폴더 안에 연습.txt가 있고, 파일 이름 뒤 .txt가 보이며, 안에 연습입니다가 두 번 보인다. 막힐 때: 파일이 내가게에 없다 → 다른 곳에 저장된 것입니다. 파일을 끌어서 내가게에 넣거나 손을 들어 주세요. 한글이 안 써진다 → 한/영 키를 한 번 누릅니다. 꼬리표가 안 보인다 → 창을 닫았다 다시 엽니다. 그래도 안 되면 손을 들어 주세요.

카드 3. 앱에서 내가게 열고 첫 요청

가게 이름은 [  ] 입니다.
파일 이름은 메모.txt 로 해 줘.
  1. 승인 요청이 뜨면 읽습니다. 파일 이름이 메모.txt이고 내가게에 만드는 것이 맞으면 허용합니다 [화면 확인 필요: 허용 버튼 이름].

성공 기준: 내가 직접 연 메모.txt에 내 가게 이름이 적혀 있고, 화면에 내가게가 열려 있으며 모드가 Manual이다. 막힐 때: 폴더가 안 열린다 → 이름이 정확히 내가게인지, 바탕화면에 있는지 확인하고 다시 합니다. 승인 창이 안 뜬다 → 조금 기다리고, 없으면 손을 들어 주세요. 엉뚱한 폴더나 이름이 보이면 허용하지 말고 손을 들어 주세요. 파일이 없다 → AI가 "만들었다"고 해도 안 된 것입니다. "메모.txt가 내가게 폴더에 없어요. 다시 만들어 줘"라고 보냅니다.

다시 처음부터 하겠습니다. 방금 만든 파일은 쓰지 말고, 계획만 먼저 알려 주세요.

AI가 계획 끝에 질문을 했다 → 아는 것만 답하고, 모르면 "모르겠습니다. [입력 필요]로 남겨 주세요"라고 합니다.

카드 5. 승인하고 만들기

목표: "좋아요" 하고 AI가 내가게 안에 index.html을 만들게 하며, 승인 창을 읽고 자체 점검 3항목을 받습니다.

알아 둘 것

  • Code 탭의 AI는 내 폴더 안에 파일을 직접 만듭니다. 복사해서 저장하지 않아도 됩니다.
  • 파일을 만들기 전에 무엇이 바뀌는지 보여 주고 내 승인을 기다립니다 [화면 확인 필요: 변경 표시의 모양, 승인·거절 버튼의 이름]. 처음 만드는 파일은 길게 보여도 코드를 읽을 필요는 없습니다.

하는 일

  1. 아래 문장을 붙여넣고 보냅니다.
좋아요. 이제 만들어 주세요.
다 만든 뒤에 아래 세 가지를 알려 주세요.
1. 제가 준 정보와 다르게 쓴 부분이 있는지
2. "[입력 필요]"로 남긴 곳은 어디인지
3. 만든 파일의 이름과 위치
  1. 승인 창이 나오면 승인 기준을 확인합니다. 파일 이름이 index.html이고, 위치가 내가게 폴더 안입니다. 다른 이름·다른 폴더가 보이면 승인하지 말고 손을 듭니다.
  2. 기준에 맞으면 승인 버튼을 누릅니다 [화면 확인 필요: 승인 버튼 이름].
  3. AI의 자체 점검 세 가지 답을 읽습니다.

성공 기준: 내가게 폴더 안에 index.html이 생겼고, AI가 세 가지를 답했다. 주의: 자체 점검은 AI의 말일 뿐입니다. AI가 "다른 점 없음"이라고 해도 다음 카드에서 내가 직접 눈으로 맞춰 봅니다. 막힐 때: 승인 버튼이 안 보인다 → 화면을 아래로 내려 보고, 없으면 손을 들어 주세요. 파일이 안 만들어졌다 → "index.html 파일을 내가게 폴더에 만들어 주세요"라고 보냅니다. 오래 걸린다 → 조금 기다리고, 그래도 멈춰 있으면 손을 들어 주세요.

카드 6. 열어 보고 눈으로 확인

목표: 만들어진 index.html을 내가 직접 열고, 숫자를 내 눈으로 맞춰 봅니다. 하는 일

  1. 바탕화면의 내가게 폴더를 파일 탐색기(맥은 Finder)로 직접 엽니다. Claude 앱이 아닙니다.
  2. index.html을 더블클릭합니다.
  3. 인터넷 창에 우리 가게(의원) 페이지가 뜨는지 봅니다. 맨 위에 "수업 연습용 페이지입니다"가 있는지도 봅니다.
  4. 내가 처음에 적은 정보와 하나씩 맞춰 봅니다. 아래 체크를 합니다.

성공 기준: 내 가게 이름이 보이는 페이지가 열리고, 아래 체크를 내 눈으로 했다. 막힐 때: 글자가 깨진다 → Code 탭에 "한글이 깨지지 않게 다시 만들어 주세요"를 보냅니다. index.html이 메모장 같은 다른 프로그램으로 열린다 → 손을 들어 주세요 [화면 확인 필요: 연결 프로그램 처리]. 파일이 없다 → 카드 5로 돌아갑니다. 참고: 주소창에 file:/// 같은 글자가 보이면 정상입니다. 아직 내 컴퓨터 안에서만 보이는 중이고, 인터넷에 올라간 것이 아닙니다.

카드 7. 말로 고치기

목표: 코딩을 몰라도 말로 한 번 고칩니다. 하는 일

  1. 아래 고치기 문장 중 하나를 고릅니다 (또는 내 말로 씁니다). 한 번에 하나만 고칩니다.
  2. Code 탭에 붙여넣고 보냅니다.
  3. 변경 표시가 나오면 어디가 바뀌는지 훑어보고, 승인 기준(index.html, 내가게 안)에 맞으면 승인합니다.
  4. 인터넷 창으로 가서 새로고침합니다 [화면 확인 필요: 새로고침 버튼 위치, 또는 F5 키].
  5. 바뀐 것을 눈으로 봅니다.

고치기 문장 예

전화번호를 더 크게 해 주세요.

맨 위에 "전화하기" 버튼을 넣어 주세요.

메뉴 가격이 더 눈에 띄게 해 주세요.  (병원: 진료시간이 더 눈에 띄게 해 주세요.)

성공 기준: 말한 대로 바뀐 것이 새로고침한 인터넷 창에서 보인다. 막힐 때: 안 바뀐 것처럼 보인다 → 인터넷 창을 새로고침했는지 봅니다. 같은 말을 더 구체적으로 다시 합니다 (예: "글자를 두 배로 크게"). 엉뚱하게 바뀌었다 → "방금 바꾼 것을 원래대로 되돌려 주세요"라고 보냅니다. 승인을 거절했다 → 같은 말을 다시 보냅니다.

카드 8. 올리기 전 점검

목표: 올려도 되는 내용인지 내 눈으로 확인합니다. 올리면 주소를 아는 사람은 누구나 볼 수 있습니다. 하는 일

  1. 내가게의 index.html을 열어 처음부터 끝까지 천천히 읽습니다.
  2. 아래 체크를 하나씩 합니다.
  3. 바탕화면의 내가게를 열었을 때 index.html이 바로 보이는지 봅니다. 폴더 안에 또 폴더가 있고 그 안에 index.html이 있으면 손을 들어 주세요.
  4. 공개하면 안 되는 파일(메모, 개인 서류)이 내가게 안에 없는지 봅니다. 연습으로 만든 메모.txt, 연습.txt가 있으면 보조에게 물어 본 뒤 폴더 밖으로 옮깁니다.

성공 기준: 아래 네 가지가 모두 체크되고, 내가게를 열면 index.html이 바로 보인다. 막힐 때: 맨 위 "연습용" 표시가 없다 → 아래 문장을 Claude에게 보내고 다시 열어 확인합니다. 파일 이름이 index.html.txt처럼 보인다 → 손을 들어 주세요.

페이지 맨 위에 작게 "수업 연습용 페이지입니다"라고 넣어 주세요.

카드 9. 내 계정으로 올리기

목표: 내가게를 내 이메일로 가입한 내 계정에 올려 인터넷 주소를 얻습니다.

오늘 쓰는 곳: [리허설 후 확정: 서비스 이름]. 아래는 틀이고, 클릭 단계는 수업 전에 채워집니다. 시간 안에 못 올려도 괜찮습니다. 수업 뒤 보조와 이어서 합니다.

알아 둘 것: 제작자(업체·지인·강사) 이름으로 만든 계정에 올리면 내 것이 아닙니다. 내 것이 되는 세 가지는 호스팅 계정(건물의 계약서), 도메인(간판 주소), 사이트 파일(설계도)입니다. 오늘은 계정과 파일을 내 손에 둡니다.

하는 일

  1. 올리는 곳에 내 이메일로 로그인합니다 [리허설 후 확정: 주소]. 비밀번호는 내가 직접 입력하고 옆 사람·강사·AI가 대신 넣지 않습니다.
  2. 올리는 곳으로 이동합니다 [리허설 후 확정: 메뉴 이름].
  3. 내가게 폴더(또는 zip)를 올리는 칸 위로 끌어다 놓습니다 [리허설 후 확정: 폴더로 할지 zip으로 할지].
  4. 올라가는 것이 끝나길 기다립니다 [리허설 후 확정: 완료 표시].
  5. 서비스가 보여 주는 주소를 복사합니다 [리허설 후 확정: 주소 위치].
  6. 돈을 내라는 화면이 나오면 멈추고 손을 듭니다 [확인 필요: 결제 수단 요구 여부].

성공 기준: https://로 시작하는 주소가 생겼다. 막힐 때: 끌어다 놓아도 반응이 없다 → 마우스 왼쪽 버튼을 누른 채 칸 위까지 옮기고 놓으세요. 안 되면 손을 들어 주세요. 올라갔는데 내용이 이상하다 → 카드 8의 index.html 위치를 다시 확인합니다. 화면이 영어라서 모르겠다 → 손을 들어 주세요. 보조가 같이 봅니다. 시간이 다 됐다 → 수업 뒤 보조와 이어서 합니다.

주소가 생겼다고 끝난 것이 아닙니다. 다음 카드에서 휴대폰으로 열어야 완료입니다. - [ ] 내 이메일로 만든 내 계정에 올렸다 - [ ] 주소가 생겼다 (못 올렸으면 수업 뒤 보조와 이어서 합니다)

카드 10. 휴대폰으로 열어 보기

목표: 내 휴대폰에서 내 사이트가 열리는지 눈으로 확인합니다. 하는 일

성공 기준: 휴대폰에서 내 가게 페이지가 열린다. 막힐 때: 안 열린다 → 주소가 https://로 시작하는지, 글자가 빠지지 않았는지, 와이파이나 데이터가 켜져 있는지 봅니다. 예전 페이지나 빈 화면이 보인다 → 손을 들어 주세요.

AI나 사이트가 "올렸습니다"라고 말한 것만으로는 완료가 아닙니다. 내 휴대폰에서 열려야 완료입니다. - [ ] 휴대폰에서 열렸다 - [ ] 열린 화면을 사진으로 찍어 두었다

오늘 수업에서 하지 않는 것 — 집에서 이렇게 하면 됩니다

오늘은 하지 않았습니다. 아래는 "이렇게 하면 됩니다" 수준의 안내이고, 화면과 요금은 직접 확인하세요. 막히면 보조나 후속 수업에서 물어 보세요.

1. 고친 뒤 다시 올리기 (재배포)

  1. Claude 앱 → Code 탭 → 내가게 폴더를 열고(카드 3), 말로 고칩니다(카드 7).
  2. 바뀐 index.html을 내 눈으로 확인합니다(카드 6, 8).
  3. 오늘 올린 같은 계정, 같은 사이트에 다시 올립니다 [리허설 후 확정: 다시 올리는 방법과 주소가 그대로인지 여부].
  4. 내 휴대폰으로 주소를 열어 바뀐 것을 확인합니다(카드 10).

2. 자동 답변 문구 만들기

  1. 손님이 자주 묻는 질문 3개를 종이에 적습니다 (예: 영업시간, 주차, 휴무일).
  2. 사실은 내가 주고, AI에게는 문장만 쓰게 합니다. 내가 주지 않은 사실은 쓰지 말고 [입력 필요]로 남기게 합니다.
  3. 나온 문구의 숫자·시간을 내 눈으로 원본과 맞춰 봅니다. 병원은 원장이 검수하고, 효과 보장·과장·비교 표현은 쓰지 않습니다.
  4. 손님 이름, 전화번호는 AI에게 보내지 않습니다.

3. 글쓰기 비서 만들기

  1. 전할 내용을 메모로 짧게 적어 AI에게 줍니다 (사실은 메모 안에 있는 것만).
  2. 초안을 받으면 메모와 한 줄씩 맞춰 봅니다. 메모에 없는 문장이 슬쩍 들어갔는지 찾습니다.
  3. 마지막에는 사람(나)이 읽고 내 말투로 고칩니다.

4. 도메인 알아보기

  1. 도메인은 연 단위로 빌리는 내 명의 주소입니다. 갱신을 놓치면 잃을 수 있습니다.
  2. 돈이 듭니다 [확인 필요: 가격]. 구입과 결제는 내가 직접 합니다. 강사·AI가 대신 하지 않습니다.
  3. 구입 뒤 내 사이트와 연결하는 일(DNS)은 어렵습니다. 업체 상담이나 보조와 함께 합니다.
  4. 도메인이 없어도 사이트는 서비스가 준 주소로 열립니다. 서둘러 사지 않아도 됩니다.
